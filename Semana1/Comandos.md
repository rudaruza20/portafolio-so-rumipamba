# Listado de Comandos básicos
## S.O. Windows con PowerShell

### Ver caracteráticas de la CPU
```
Get-CimInstance Win32_Processor​
```
### Ver caracteríticas de la Memoria RAM
```
Get-CimInstance Win32_PhysicalMemory​
```
### Ver propiedades del disco duro
```
Get-PhysicalDisk
```
```
Get-Volume​
```
### Ver propiedades de E/S
```
Get-PnpDevice -PresentOnly​
```
### Ver resumem de propiedades del hardwarew
```
systeminfo
```
```
msinfo32​
```
